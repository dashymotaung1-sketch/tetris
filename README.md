# tetris
What is Tetris?

Tetris is a classic puzzle game where different shaped blocks (called tetrominoes) fall from the top of the screen. Your job is to move and rotate these pieces to create complete horizontal lines. When you complete a line, it disappears, you earn points, and the game gets faster!

🎯 Game Objective

Your goal is to prevent the pieces from stacking to the top by:

    Moving and rotating falling pieces

    Creating complete horizontal lines

    Clearing multiple lines at once for bonus points
